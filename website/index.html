Everything a completionist needs

Built from the ground up for Steam achievement hunting — no bloat, no accounts, no cloud required.

Real-time Detection

FileSystemWatcher monitors your Steam and emulator folders instantly. Achievements appear the moment they unlock — no polling, no delays.

OBS Overlay (SSE)

Built-in HTTP server pushes unlocks via Server-Sent Events. Add as a browser source in OBS — fully customizable HTML/CSS/JS templates included.

Rarity Tiers & Stats

Steam global rarity percentages with color-coded tiers (Common → Exclusive). Streak tracking, completion rates, CSV export — all local.

Backup & Restore

One-click zip backups with manifests, automatic pruning, safety copies, and zip-slip protection. Restore to any machine in seconds.

Steam Store Integration

Auto-fetches game names and high-res cover art from the Steam Store API — no API key needed. Cached locally for offline use.

Screenshot Capture

DPI-aware screenshots on unlock (per-monitor v2). Saved organized by game/achievement with timestamps — perfect for sharing.

Save Game Locator

Downloads and parses Ludusavi manifests to find save paths automatically. Works across Steam, Epic, GOG, Xbox, EA, Ubisoft, and more.

System Tray & Global Hotkeys

Runs quietly in the tray. Toggle overlay, force scan, open settings — all from customizable global hotkeys. Single-instance mutex included.

Custom Theming Engine

Built-in UI toolkit with light/dark modes, accent colors, and per-component styling. The app looks native on any Windows theme.

System Requirements

Lightweight by design — runs on any modern Windows machine.

Operating System

  • Windows 10 (1903+) or Windows 11
  • 64-bit only (x64)

Runtime

  • .NET 8 Desktop Runtime (x64)
  • Installed via Windows Update or manual download

Steam / Games

  • Steam client (for official games)
  • Or any supported emulator (Goldberg, CODEX, etc.)
  • Games with Steam achievements

Performance

  • ~10–30 MB RAM idle
  • ~50–80 MB RAM during active scanning
  • Negligible CPU when idle
  • Portable — no installation, no admin rights

Optional Enhancements

  • OBS Studio (for overlay)
  • Steam Web API key (for richer stats)
  • Ludusavi (for save game detection)

Antivirus Notes

  • Unsigned binary — may trigger SmartScreen
  • Add exception or click "More info → Run anyway"
  • Open source — verify on GitHub
  • No telemetry, no network calls except Steam APIs
